# Assets

`scotiabank-logo.webp` es el logotipo horizontal proporcionado por el usuario para este proyecto académico. Se conserva sin modificaciones y se utiliza como referencia visual en los puntos de marca de la aplicación.

El favicon se encuentra en `public/favicon.png`; contiene únicamente el isotipo extraído para navegación del navegador. La interfaz mantiene de forma visible la leyenda de proyecto universitario no oficial y no representa una afiliación institucional.
